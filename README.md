# EigenMatch — PCA-Based Face Similarity Search

Classic **eigenfaces**: PCA fit on grayscale face images, then nearest-neighbor
similarity search in that compressed PCA space using three distance metrics —
**Euclidean**, **Cosine**, and **Manhattan** — compared side by side.

**Dataset:** the Olivetti Faces dataset (AT&T Laboratories Cambridge) — 400
grayscale 64x64 images of 40 people, 10 images each. Loaded via
`sklearn.datasets.fetch_olivetti_faces()`. This needs a one-time internet
connection on first run (~4MB download); scikit-learn caches it locally under
`~/scikit_learn_data/` afterwards, so every run after that works offline.

## Setup

```bash
python -m venv venv && source venv/bin/activate   # optional but recommended
pip install -r requirements.txt
```

### Speed up cold starts (recommended before deploying)

Run this once locally, with normal internet access:

```bash
python scripts/precompute_cache.py
```

This downloads the dataset, fits the eigenfaces PCA, and saves everything
to `models/face_cache.joblib` (~6-9 MB). **Commit that file to your repo.**
From then on, `app/app.py` loads instantly from the cache instead of
re-downloading the dataset and re-fitting PCA every time the app cold-starts
(e.g. on Streamlit Community Cloud after a period of inactivity). If you
skip this step, the app still works — it just fetches + fits live on first
load, which is slower.

## Usage

### Notebook (full walkthrough)

```bash
jupyter notebook notebooks/main.ipynb
```

Covers: sample faces, eigenfaces visualization, cumulative explained
variance, a reconstruction demo (how much detail survives PCA compression),
similarity search for a query face ranked by all three metrics, and a
leave-one-out retrieval-accuracy evaluation per metric.

**Note:** the first cell that calls `fetch_olivetti_faces()` needs internet
access. If you're behind a restrictive firewall/proxy, download once on an
unrestricted connection — after that it's cached and works offline.

### Streamlit app (interactive frontend)

```bash
streamlit run app/app.py
```

- Pick any face from the built-in 40-person gallery, **or** upload your own
  grayscale (or color, auto-converted) face photo
- See the top-N most similar faces, ranked by whichever metric you choose
- Every result shows all three metrics side by side with progress bars
- Export results to CSV

## How it works

1. **Eigenfaces:** every 64x64 image (4,096 pixels) is flattened and PCA is
   fit across all 400 faces, keeping enough components to explain 95% of
   the variance (typically ~100-150 components — over a 25x compression).
2. **Similarity search:** a query face is projected into this same PCA
   space, then compared against every gallery face using:
   - **Euclidean** — straight-line distance; general purpose
   - **Cosine** — angle between vectors; ignores overall brightness/contrast
   - **Manhattan** — sum of absolute differences; more robust to a few
     large outlier dimensions
3. **Evaluation:** since each face's true identity is known, retrieval
   quality is checked directly — for every face, treat it as a query
   against every other face and see whether the top-k matches share the
   same person. This is done for every metric so you can see which one
   actually retrieves the correct person most reliably.

## Extending this

- Swap in your own face dataset (any folder of grayscale images resized to
  a consistent shape works with the same `face_similarity.py` functions).
- Add a deep face-embedding model (FaceNet, ArcFace, etc.) as a fourth
  comparison point — eigenfaces are a fast, fully classical baseline, but
  deep embeddings are typically far more robust to lighting/pose changes.
- Swap the `st.cache_resource`-cached in-memory gallery for FAISS if you
  want this to scale to a much larger face collection.
